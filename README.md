# tesserclip.com

The marketing and help website for [TesserClip](https://tesserclip.com), BrightDigit’s macOS app that opens straight to the text you last copied, so you can fix it before you paste it.

The site is static: Astro 7 and Tailwind CSS 4, deployed to GitHub Pages.

```bash
mise install      # Node 24
make install
make dev          # local dev server
make build        # build to dist/
make check-links  # verify internal links and required paths
```
